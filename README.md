# 🤖 24-Hour Automated Trading Bot (MQL4)

An automated Forex Expert Advisor (EA) developed in MQL4 for MetaTrader 4 (MT4) designed to execute trading strategies continuously across market sessions.

---

## 📌 Overview

This repository contains the source code for an automated trading script (`24hours.mq4`) built to run on MetaTrader 4. It handles entry signals, trade execution, and basic risk management parameters automatically.

---

## 🛠️ Requirements

* **Trading Platform:** MetaTrader 4 (MT4)
* **Language:** MQL4
* **Account Type:** Demo or Live MT4 Trading Account
